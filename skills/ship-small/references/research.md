# Research a blocking decision

Name the exact unknown and the choice it affects. Check local code, installed versions, and supplied documentation first. If current external facts matter, use official documentation for the actual version. Read enough to resolve that choice, cite the supporting page, and return to implementation. Stop when the next action is supported; do not generate a survey by default.

In an assessment, respect the supplied network and disclosure rules. Do not put task text, private data, code, screenshots, or answers into an external query. Prefer provided docs and allowed public reference downloads; ask the designated internal stakeholder when the missing information is business context.

Separate evidence from inference. A sample is not a guaranteed production contract. If access is blocked, record the missing source and use a reversible fallback only if acceptance allows it. Never invent research, benchmarks, citations, or interview evidence.
